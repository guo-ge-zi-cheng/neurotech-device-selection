# Evidence available for the seven device reports

This is the current information-research comparison, matched to the supplied guide on 2026-10-21. Start with the [31 common required elements](../docs/report-evidence-requirements.md). Open a device for every element's source content, direct contribution, strength, exact gap and next action.

**Strength is claim-specific:** Direct = an appropriate original record/study for the stated fact; Limited = important design/scope limits; Partial = only part answered; Model = conditional analysis; Indirect/Context = background; Mismatch = evidence concerns the wrong product/period; Missing = no accepted answer; Inference/Provisional = our analysis. A direct source can still leave fields missing.

The tables below highlight one informative evidence match per device/topic; **the linked device files contain all 31 rows**. Source checks originally date to 19–20 October unless the [new access/review log](../docs/imperial-gap-searches.md) states otherwise. No total richness/readiness score is calculated.
