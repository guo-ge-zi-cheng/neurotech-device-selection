It generates Layer 2 of each device report and docs/additional-research-summary.md. Layer 1 preserves the original device-records.json text and access labels. New catalog entries supplement the original source records; deeper use of an existing source is labelled explicitly. Use docs/reliability-protocol.md before extending this evidence.

Source use in an example is not a new verified source claim for one of our devices.
